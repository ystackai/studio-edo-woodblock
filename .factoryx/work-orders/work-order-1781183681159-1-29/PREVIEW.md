# Preview — p2-quiet-opening-b

## Path
`games/trial-e1b-p2-quiet-opening-b/index.html`

## How to preview
1. Serve the repo root (e.g. `python3 -m http.server 8000` from `checkout/`)
2. Navigate to `http://localhost:8000/games/trial-e1b-p2-quiet-opening-b/index.html`
3. Or open the file directly in a browser

## What to expect
A single canvas fills the screen. The scene shows a lone pine tree on a cliff edge, overlooking a vast foggy sea. The first frame is the complete piece — no intro, no prompt. Moving your pointer (or finger) gently parts the fog, revealing more of the scene. The sea waves breathe slowly; the fog shifts and drifts. Everything is procedural — no external assets needed.

## Interaction
- Mouse move / touch drag: parts fog around cursor
- Touch works on mobile
- No keyboard input
- No audio
