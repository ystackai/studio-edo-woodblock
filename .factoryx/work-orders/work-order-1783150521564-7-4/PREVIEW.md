# Preview — Q3 Blocks Mini Live v4

**Preview entrypoint:** `games/q3-blocks-mini-live-v4/index.html`

**Creative intent:** This should feel like watching colored blocks cascade and lock into place like pieces of a woodblock print, with the satisfying snap of clearing complete rows.

**How to play:** Open `index.html` in a browser. Blocks fall automatically. Arrow keys or A/D to move, Up/W to rotate, Space to hard drop. Clear rows for points.
