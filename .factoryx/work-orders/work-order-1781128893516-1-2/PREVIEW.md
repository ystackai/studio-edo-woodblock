# Preview

- **Path**: `games/living-print/index.html`
- **Type**: Single self-contained HTML file
- **Payload**: ~15KB (no external assets, no network requests)
- **Opens immediately** — no loading state, no instructions needed
- **Interaction**: Press and hold anywhere on the canvas. The ink deepens under your finger like a baren pressing on a woodblock. Release to let it settle.

**How to preview locally:**
Open `games/living-print/index.html` in a browser. Or serve from the repo root and navigate to `games/living-print/`.
