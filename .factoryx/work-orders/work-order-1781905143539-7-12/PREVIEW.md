# PREVIEW — kawanakajima-samurai-world

Open the playable 3D browser experience:

`games/kawanakajima-samurai-world/index.html`

- Serve the repo over HTTP, then open `/games/kawanakajima-samurai-world/` so GLB imports work.
- First viewport shows the repaired v3 20-samurai countryside scene (non-blank 3D).
- Drag to orbit, wheel to zoom. Camera frames the armies.
- Click samurai to inspect.
- Use "Sound the charge" or press C — world state changes (actors advance, some fall, morale updates, possible win/loss).
- "Reform lines" or R resets the encounter loop.
