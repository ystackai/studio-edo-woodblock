# Preview: trial e1b/a — p2-quiet-opening

## Artifact
`games/trial-e1b-p2-quiet-opening-a/index.html`

## Description
A lone pine on a sea cliff in fog. No tutorial, no prompt to begin — the first screen is already a finished compositional statement.

## How to preview
Open the file directly in a browser:
```
games/trial-e1b-p2-quiet-opening-a/index.html
```

## What to experience
- **Opening frame**: The piece opens immediately on a muted, atmospheric landscape — fog moves slowly across the scene
- **Fog movement**: Six layers of fog drift at different speeds and directions, creating depth
- **Pointer drift**: Moving the cursor subtly parts the fog, revealing more of the scene around the pointer
- **Paper grain**: A subtle procedural paper texture overlays the entire piece
- **Sea**: Gentle wave shimmer at the horizon line
- **Cliff**: Jagged cliff face with the lone pine silhouetted against the fog
- **Motes**: Tiny floating particles drift through the air like mist particles

## Technical
- Single self-contained HTML file (12 KB)
- Canvas-based rendering at up to 2x device pixel ratio
- No external dependencies — works offline
- Responsive: adapts to any screen size
- No audio, no user interaction required beyond observation
