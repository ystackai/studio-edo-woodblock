### How to preview

1. Open the GitHub preview or clone the repo
2. Navigate to `games/trial-e3-p1-living-print/index.html`
3. The living print loads immediately — no loading state

### Interaction

- Move the cursor over the canvas to hover
- Press and hold (click/touch) to apply a baren press — the mist pushes aside, ripple rings emerge, ink deepens
- Release to let the scene settle back
