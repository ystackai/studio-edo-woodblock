# Preview — Q3 blocks mini-live v12

- **Preview entrypoint**: `games/q3-blocks-mini-live-v12/index.html`
- **Title**: Midnight Canal
- **Game**: 2D dodge game — steer a boat through a midnight canal, avoiding floating logs and crates
- **Controls**: Arrow keys / A-D to steer, tap/click to start and to restart
- **Audio**: WebAudio drone pad starts on first gesture; whoosh on debris spawn, pickup every 5 dodges, fail on collision
- **Phase machine**: waiting → playing → hit → debrief → waiting (loop)
- **Foundry modules**: game-loop.js, input.js, webaudio-kit.js — all copied verbatim
